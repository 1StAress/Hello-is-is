Backup & Restore

สำรองและกู้คืนข้อมูลในเบราว์เซอร์เครื่องนี้ โดยไม่ส่งข้อมูลออกไปยังเซิร์ฟเวอร์

สถานะข้อมูลปัจจุบัน

ระบบอ่านค่า Storage ดิบโดยตรง ไม่ใช้ OPS.load() เพื่อไม่ให้ข้อมูล JSON ที่เสียหายถูกเข้าใจผิดว่าเป็นข้อมูลว่าง

กำลังตรวจสอบข้อมูล...
หากพบข้อมูลที่อ่านไม่ได้ ระบบจะหยุดการสำรองหรือกู้คืนที่อาจทำให้ข้อมูลสูญหาย และจะไม่แก้ไขคีย์นั้นให้อัตโนมัติ

ตรวจสอบไฟล์และกู้คืน

เลือกไฟล์สำรองจาก OPS Portal แล้วตรวจสอบก่อน ระบบจะไม่เขียนข้อมูลระหว่างขั้น Preview

Preview ก่อนกู้คืน

การกู้คืนจะแทนที่ข้อมูลใน Storage Keys ทั้ง 7 รายการด้วยข้อมูลจากไฟล์ หลังจากดาวน์โหลดสำเนาข้อมูลปัจจุบันและยืนยันอีกครั้ง
ยังไม่มีไฟล์ที่ผ่านการตรวจสอบ

ข้อควรทราบ

  • ระบบนี้สำรองเฉพาะ 7 Storage Keys ที่กำหนด ไม่ได้สำรอง sessionStorage รหัสผ่าน ไฟล์ในเครื่อง หรือการตั้งค่าของเบราว์เซอร์
  • ข้อมูลรูปภาพที่เก็บเป็น Data URL ภายในรายการจะถูกเก็บไว้ตามเดิม
  • การกู้คืนหลายคีย์ไม่ใช่ธุรกรรมแบบ Atomic หากการเขียนล้มเหลว ระบบจะพยายามคืนค่า raw value เดิมทุกคีย์และรายงานผล
  • อย่าปิดหน้าเว็บหรือเปิดโมดูลอื่นระหว่างการกู้คืน
